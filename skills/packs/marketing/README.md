# Marketing skill pack (sample)

A starting set for a marketing teammate. Every skill here runs at the `draft` tier: it writes a draft for a person to review and never publishes, posts or sends.

- `campaign-brief`: turns a goal into a one-page campaign brief.
- `launch-checklist`: builds a launch checklist from a feature ticket.
- `weekly-metrics-summary`: summarizes the week's numbers that a person pastes or exports.

No code workers in this pack. Uses an organization-owned Claude key, never a personal one.

To adapt it: copy the folder, change `owner`, edit the steps in plain language, and get each skill reviewed before it touches real data.
